Qu'est-ce qui change concrètement ?

Thunderbird est un excellent logiciel, mais son interface historique peut paraître austère et encombrée. Voici la différence :

Thunderbird par défaut

Interface Traditionnelle

  • ❌ Angles droits stricts et barres grises d'ancienne génération.
  • ❌ Boutons compacts parfois difficiles à distinguer.
  • ❌ Messages serrés sous forme de tableur austère.
  • ❌ Liens de désinscription des newsletters invisibles ou cachés tout en bas.
Avec Material-Thunderbird

Interface Material You (M3)

  • ✅ Formes douces en pilules et couleurs tonales apaisantes pour les yeux.
  • ✅ Grand bouton d'action flottant "Écrire" (Extended FAB) bien visible.
  • ✅ Courriers organisés sous forme de cartes blanches aérées.
  • ✅ Bandeau de désinscription automatique en 1 clic au-dessus des newsletters.

Installation Simple & Rapide

Comment installer ce thème ?

Pas besoin de s'y connaître en informatique ! Choisissez votre système ci-dessous et laissez-vous guider étape par étape.

1

Télécharger le Pack

Cliquez sur le gros bouton ci-dessous pour télécharger le dossier contenant le thème et son installateur automatique.

📥 Télécharger le Pack Facile (.ZIP)
(ou télécharger l'archive complète depuis GitHub)
2

Extraire le Dossier

Dans votre dossier Téléchargements, faites un clic droit sur le fichier téléchargé, puis choisissez :
📂 "Extraire tout..." puis cliquez sur Extraire.

3

Double-cliquer pour installer

Ouvrez le dossier extrait et faites un double-clic sur :

👉 Installer-Material-Thunderbird.bat

Une petite fenêtre se charge d'activer le thème en quelques secondes. Relancez ensuite Thunderbird !

ℹ️

Windows affiche un écran bleu "Windows a protégé votre ordinateur" ?

Ne vous inquiétez pas, c'est tout à fait normal ! Windows affiche cette précaution de sécurité pour tous les projets bénévoles et gratuits qui n'achètent pas de certificat d'entreprise commercial payant auprès de Microsoft.

1️⃣ Cliquez sur le petit texte Informations complémentaires
2️⃣ Cliquez sur le bouton Exécuter quand même
⚠️ Information importante sur l'extension .XPI

1. Message « Ce module semble corrompu » : Dans les versions officielles stables de Mozilla Thunderbird, glisser-déposer un fichier .xpi externe affiche cette fausse alerte de corruption, car Thunderbird bloque par défaut les extensions non signées sur addons.thunderbird.net.
2. Personnalisation incomplète via .XPI seul : Par mesure de sécurité, Thunderbird interdit aux extensions WebExtensions d'injecter des styles dans l'interface interne (panneau des dossiers, barre d'outils unifiée, cartes de conversation, etc.).

👉 Méthode complète et recommandée : Utilisez l'onglet 🪟 Windows (1-Clic Recommandé) ci-dessus avec le Pack Facile (.bat). Il installe automatiquement tous les styles Material 3, active les préférences nécessaires et déploie l'assistant sans aucun avertissement !
1

Télécharger le fichier .xpi

Si vous développez ou utilisez Thunderbird Developer Edition / Beta avec signatures désactivées :

📥 Télécharger (.XPI)
2

Mode Développeur ou Profil

Dans Thunderbird, ouvrez about:debugging puis cliquez sur Ce Thunderbird > Charger un module temporaire... ou placez le fichier dans le dossier extensions/ de votre profil.

3

Activer les styles chrome/

Pour profiter de l'intégralité du design (dossiers, barre de navigation, cartes), copiez également le dossier chrome/ dans votre profil.

Installation Manuelle Pas à Pas (macOS & Linux)

  1. Activer les styles personnalisés dans Thunderbird :
    Allez dans Paramètres > onglet Général > tout en bas, cliquez sur Éditeur de configuration...
    Recherchez toolkit.legacyUserProfileCustomizations.stylesheets et double-cliquez dessus pour le passer à true.
  2. Ouvrir votre dossier de profil :
    Dans le menu, allez dans Aide > Informations de dépannage. À la ligne Dossier de profil, cliquez sur Ouvrir le dossier (ou Afficher dans le Finder sur Mac).
  3. Copier les fichiers du thème :
    Dans ce dossier de profil, créez un sous-dossier nommé chrome et copiez-y l'intégralité du contenu du dossier chrome/ de ce dépôt.
  4. Redémarrez Mozilla Thunderbird pour apprécier le nouveau design !

Installation Express via PowerShell (Windows 10/11)

Si vous préférez installer le thème directement sans télécharger d'archive : ouvrez PowerShell (Menu Démarrer > tapez PowerShell) et collez simplement cette commande :

irm https://raw.githubusercontent.com/VForiel/Material-Thunderbird/main/scripts/web-install.ps1 | Invoke-Expression

Cette commande télécharge automatiquement les fichiers nécessaires, déploie le thème dans votre profil Thunderbird et configure les paramètres sans rien casser.

💡 Depuis l'Invite de commandes (CMD) ou le raccourci Win+R, utilisez : powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/VForiel/Material-Thunderbird/main/scripts/web-install.ps1 | Invoke-Expression"

↩️ Vous voulez revenir à l'ancienne apparence ?

C'est très simple et garanti sans risque : double-cliquez sur le fichier Desinstaller-Material-Thunderbird.bat dans le dossier téléchargé, puis relancez Thunderbird. Tout redevient instantanément comme avant.

Foire Aux Questions

Des questions ? Nous avons les réponses !

Tout ce qu'il faut savoir pour installer et utiliser le thème en toute sérénité.

Absolument aucun risque. Le thème ne modifie que la "peinture" extérieure de Thunderbird (les couleurs, la forme des boutons et les polices). Il ne touche ni à vos comptes, ni à vos mots de passe, ni au stockage de vos courriels.
Ce thème est 100% gratuit et libre (licence open-source MIT). Il n'y a aucune publicité, aucun abonnement, aucune collecte de données et aucun compte à créer.
C'est une protection automatique de Windows (SmartScreen) qui s'affiche pour tous les programmes créés par des développeurs indépendants ou des bénévoles qui ne paient pas de licence annuelle onéreuse à Microsoft. Vous pouvez cliquer sur "Informations complémentaires" puis "Exécuter quand même" en toute sécurité. Le code source est totalement public et vérifiable sur GitHub.
Assurez-vous d'avoir complètement fermé et rouvert Thunderbird. Si Thunderbird était resté réduit à côté de l'horloge Windows, fermez-le complètement (ou redémarrez votre ordinateur) pour que les nouveaux styles se chargent.
L'installateur a créé un fichier spécial nommé chrome/user-overrides.css dans votre profil. Vous pouvez y choisir très facilement votre couleur préférée en suivant les exemples simples décrits dans le Guide de Personnalisation.
Faites simplement un double-clic sur le fichier Desinstaller-Material-Thunderbird.bat présent dans le dossier téléchargé. Vos paramètres d'origine seront restaurés automatiquement et proprement.
