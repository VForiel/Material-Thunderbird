Politique de confidentialité

Extension Material-Thunderbird (« Material You Thunderbird ») · version du 12 novembre 2026

L'extension ne collecte rien pour son auteur : pas de compte, pas de statistiques, pas de télémétrie, pas de publicité. Elle travaille dans votre Thunderbird. Trois fonctions contactent des serveurs tiers, et chacune peut être désactivée dans la fenêtre de personnalisation (bouton palette ou Alt+M).

Ce qui part sur Internet

Logos des marques activé par défaut

Pour afficher le logo officiel d'un expéditeur (Doctolib, une banque…) à la place de son initiale, comme le fait Gmail, l'extension lit deux enregistrements DNS publics du domaine de l'expéditeur : default._bimi.<domaine> et _dmarc.<domaine>.

  • Ces requêtes passent par le résolveur DNS de votre système. S'il ne sait pas répondre à ce type de requête, elles passent par le service DNS chiffré de Cloudflare (cloudflare-dns.com), qui voit alors le nom de domaine demandé et votre adresse IP. Au premier usage, une requête de test porte sur google.com.
  • Si le domaine publie un logo et une politique anti-usurpation stricte, le logo (une image SVG de 64 Ko au plus) est téléchargé, sans cookie, depuis l'adresse que le domaine a publiée : souvent son propre serveur, parfois une autorité de certification comme DigiCert.
  • Ce qui est transmis : le nom de domaine des expéditeurs et votre adresse IP. Jamais l'adresse complète, l'objet ni le contenu d'un message.
  • Ce qui est conservé : dans les préférences de Thunderbird, l'adresse du logo de chaque domaine déjà consulté (7 jours si un logo existe, 1 jour sinon). L'image elle-même reste en mémoire le temps de la session.

Pour désactiver : Alt+M › Avatars › Logos des marques.

Gravatar désactivé par défaut

Si vous l'activez, l'extension demande à gravatar.com (Automattic) la photo publique associée à l'adresse de l'expéditeur. L'adresse est envoyée sous forme d'empreinte SHA-256 : c'est une protection faible, car l'empreinte d'une adresse connue se retrouve facilement. Gravatar apprend aussi, par votre adresse IP, à quel moment vous lisez un message de cette personne.

Pour activer ou désactiver : Alt+M › Avatars › Gravatar.

Désinscription des infolettres seulement quand vous cliquez

Le repérage du lien de désinscription se fait dans Thunderbird, à partir des en-têtes et du contenu du message affiché : rien n'est envoyé pour cela. Quand vous cliquez sur « Se désinscrire » :

  • si l'expéditeur accepte la désinscription en un clic, une requête POST contenant seulement List-Unsubscribe=One-Click est envoyée, sans cookie, à l'adresse indiquée par l'expéditeur dans le message ;
  • sinon, la page de l'expéditeur s'ouvre dans un onglet de Thunderbird, ou un brouillon d'e-mail est préparé, que vous relisez et envoyez vous-même.

Pour désactiver le bandeau : Alt+M › Proposer la désinscription.

Autres connexions

  • Mises à jour. Version installée depuis ce site : Thunderbird consulte une fois par jour le fichier updates.json hébergé par GitHub Pages, qui voit votre adresse IP. Version installée depuis addons.thunderbird.net : les mises à jour passent par cette boutique.
  • Bouton « Soutenir ». Il ouvre GitHub Sponsors, seulement quand vous cliquez dessus.

Ce qui reste sur votre ordinateur

  • Vos réglages (couleur, apparence, icônes, options) sont enregistrés dans les préférences de Thunderbird (extensions.material-thunderbird.*), avec la liste des expéditeurs ou des messages pour lesquels vous avez masqué le bandeau de désinscription.
  • Si vous choisissez le mode Clair ou Sombre, l'extension règle la préférence ui.systemUsesDarkTheme de Thunderbird, et la rend à Thunderbird quand l'extension est désactivée ou désinstallée.
  • Le bouton « Désinstaller » de la fenêtre Alt+M efface toutes ces préférences, puis retire l'extension. L'extension n'écrit aucun fichier dans votre profil.

Permissions demandées

  • Lire vos messages (messagesRead) et scripts d'affichage des messages : pour repérer, dans le message affiché, le lien de désinscription. Rien n'est transmis.
  • Accès complet à Thunderbird (API « Experiment ») : pour appliquer le thème à toute l'interface, ajouter la fenêtre de personnalisation, masquer les réponses déjà lues et afficher les avatars.

Ce site

Ce site est hébergé par GitHub Pages, qui peut journaliser votre adresse IP. Il n'utilise ni cookie, ni outil de statistiques, ni ressource d'un autre site. L'apparence que vous choisissez avec le bouton palette est gardée dans le stockage local de votre navigateur.

Contact

Une question ou un doute : ouvrez un ticket sur GitHub. Le code source de l'extension est public et peut être vérifié : github.com/VForiel/Material-Thunderbird.

Privacy policy

Material-Thunderbird extension ("Material You Thunderbird") · version of 12 November 2026

The extension collects nothing for its author: no account, no analytics, no telemetry, no ads. It runs inside your Thunderbird. Three features contact third-party servers, and each one can be turned off in the customization dialog (palette button or Alt+M).

What goes over the network

Brand logos on by default

To show a sender's official logo instead of their initial, as Gmail does, the extension reads two public DNS records of the sender's domain: default._bimi.<domain> and _dmarc.<domain>.

  • These lookups go through your system's DNS resolver. When it cannot answer this kind of query, they go through Cloudflare's encrypted DNS service (cloudflare-dns.com), which then sees the domain name and your IP address. On first use, a test lookup is made for google.com.
  • If the domain publishes a logo and a strict anti-spoofing policy, the logo (an SVG image of at most 64 KB) is downloaded without cookies from the address the domain published: often its own server, sometimes a certificate authority such as DigiCert.
  • What is sent: the senders' domain names and your IP address. Never a full address, a subject or any message content.
  • What is kept: in Thunderbird's preferences, the logo address of each domain already looked up (7 days when a logo exists, 1 day otherwise). The image itself only stays in memory for the session.

To turn it off: Alt+M › Avatars › Logos des marques.

Gravatar off by default

When enabled, the extension asks gravatar.com (Automattic) for the public picture tied to the sender's address. The address is sent as a SHA-256 hash, which is weak protection: the hash of a known address is easy to match. Gravatar also learns, from your IP address, when you read a message from that person.

To turn it on or off: Alt+M › Avatars › Gravatar.

Newsletter unsubscribe only when you click

Unsubscribe links are found inside Thunderbird, from the headers and content of the displayed message: nothing is sent for that. When you click "Se désinscrire":

  • if the sender supports one-click unsubscribe, a POST request containing only List-Unsubscribe=One-Click is sent, without cookies, to the address given by the sender in the message;
  • otherwise, the sender's page opens in a Thunderbird tab, or an email draft is prepared, which you review and send yourself.

To turn the banner off: Alt+M › Proposer la désinscription.

Other connections

  • Updates. Version installed from this site: once a day, Thunderbird checks the updates.json file hosted on GitHub Pages, which sees your IP address. Version installed from addons.thunderbird.net: updates come from that store.
  • "Support" button. It opens GitHub Sponsors, only when you click it.

What stays on your computer

  • Your settings (color, appearance, icons, options) are stored in Thunderbird's preferences (extensions.material-thunderbird.*), together with the senders or messages for which you dismissed the unsubscribe banner.
  • If you pick Light or Dark mode, the extension sets Thunderbird's ui.systemUsesDarkTheme preference, and gives it back when the extension is disabled or removed.
  • The "Désinstaller" button in the Alt+M dialog clears all these preferences, then removes the extension. The extension writes no file to your profile.

Permissions

  • Read your messages (messagesRead) and message display scripts: to find the unsubscribe link in the displayed message. Nothing is sent.
  • Full access to Thunderbird ("Experiment" API): to style the whole interface, add the customization dialog, hide already-read replies and show avatars.

This website

This site is hosted on GitHub Pages, which may log your IP address. It uses no cookies, no analytics and no resources from other sites. The appearance you pick with the palette button is kept in your browser's local storage.

Contact

Questions or concerns: open an issue on GitHub. The extension's source code is public and can be checked: github.com/VForiel/Material-Thunderbird.
